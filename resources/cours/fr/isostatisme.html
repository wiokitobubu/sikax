Isostatisme et hyperstatisme

Définition

Un mécanisme est isostatique quand le principe fondamental de la statique suffit à calculer toutes les actions de liaison. S'il reste plus d'inconnues que d'équations indépendantes, il est hyperstatique ; le nombre d'inconnues en trop est le degré d'hyperstatisme h.

Formule

h = Is − Es + m

  • Is : somme des inconnues statiques des liaisons ;
  • Es : nombre d'équations du PFS, 3·(N − 1) dans le plan, 6·(N − 1) dans l'espace ;
  • m : mobilité.

Approche cinématique équivalente : h = Ec − rc, où Ec = 3γ (6γ dans l'espace) est le nombre d'équations de fermeture des γ boucles et rc leur rang.

Conséquences

  • h = 0 : efforts déterminés par la statique ; le montage tolère les défauts de fabrication.
  • h > 0 : la répartition des efforts dépend des jeux, des déformations et des tolérances. Plus rigide, mais exige un montage précis. Sikax donne alors la solution de norme minimale et le signale.

Plan ou espace ?

Un schéma plan cache des contraintes : une articulation dessinée peut être une pivot (5 inconnues dans l'espace), une rotule (3) ou une linéaire annulaire (2). Un quadrilatère articulé plan, isostatique dans le plan, est hyperstatique d'ordre 3 dans l'espace avec quatre pivots. Le modèle spatial de chaque liaison, dans ses propriétés, permet de faire l'analyse réelle dans l'onglet Validation.

Exemple : un engrenage droit à denture droite entre deux pivots parfaites est hyperstatique d'ordre 1 dans l'espace (contact linéique) ; une denture bombée (contact ponctuel) le rend isostatique.
